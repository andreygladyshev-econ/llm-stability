# Рабочий проект

Здесь лежит проект в том виде, в каком он вёлся с 14 по 29 сентября: все прогоны, версии спецификации, распознанные
тексты, очереди серий, ежедневные отчёты и рабочие заметки. Для проверки сдачи эта папка не нужна: всё, что нужно
для пересчёта чисел записки, скопировано в [../submission/code](../submission/code/README.md). Папки `raw`,
`raw_qwen_bf16`, `specs`, `queues`, `text`, `text_v2`, `text_pdf`, файл `requirements.txt` и три файла из `notes`
(соответствие отчётов файлам PDF, примечания ручной проверки, описания подменённых текстов) там такие же, как здесь;
что в них лежит, описано в README папки кода. В `src` там только скрипты для пересчёта и скрипты, которыми получены
данные; здесь в `src` есть ещё вспомогательные (см. ниже).

## Ссылки на `_АНДРЕЙ` и другие пути вне репозитория

Рядом с проектом у автора лежала личная папка `_АНДРЕЙ`: разборы ночей, план, заметки по литературе, ручная
разметка. В репозиторий она не входит, её содержание, нужное для проверки, перенесено в записку и приложения.
Ссылки на неё остались в файлах, которые менять нельзя или не нужно:

- версии спецификации в `specs/` — ровно тот текст, который видела модель: его хеш записан в каждом ответе
  (`spec_hash`), и правка любого символа разошлась бы с прогонами. Поэтому в `specs/` осталась и ссылка на
  `ЗАДАНИЕ_прост_рус_яз.md` из текста спецификации заказчика: в папке `specs` такого файла нет, он лежит в
  [../assignment](../assignment/);
- очереди в `queues/` — записи того, что запускалось; хеш очереди записан в описании окружения прогонов на
  ноутбуке (`queue_sha`);
- `src/night.py`: хеш его кода вместе с `src/indicators.py` записан в каждом прогоне (`code_sha`);
- `CLAUDE.md` и `notes/NIGHT_HANDOVER.md` — рабочие записи того времени; в `CLAUDE.md` исходники задания названы
  по старому месту (`../HACKATHON_TYPE_TASK/`), в репозитории это папка [../assignment](../assignment/);
- скрипты `src/compare_gold.py` и `src/make_labeling_form.py` работают с ручной разметкой в личной папке и без неё
  не запускаются; для пересчёта сдачи они не нужны. `src/report.py` пишет журнал результатов в личную папку, а если
  её нет — в `reports/`.

Эталонная разметка, по которой считается правильность, лежит в [../submission/gold_labels](../submission/gold_labels/README.md).

## Запуск

Окружение: Python 3.12, `python -m venv .venv && .venv/bin/pip install -r requirements.txt`. Серии прогонов
запускались командой `.venv/bin/python src/night.py start queues/<очередь>.toml` (нужна LM Studio с моделью) и
`src/cloud.py` (нужен ключ OpenRouter, в код не включён). Пересчёт по сохранённым ответам описан в
[../submission/code/README.md](../submission/code/README.md); здесь те же скрипты запускаются так же, из этой папки.
