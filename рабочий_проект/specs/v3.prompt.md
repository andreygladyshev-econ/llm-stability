Правила работы:
- Используй только текст отчёта, который дан ниже. Никаких внешних знаний о банке, рынке, котировках и новостях.
- Текст получен распознаванием скана, в нём бывают ошибки: латинские буквы вместо русских, разорванные слова.
- Для каждого из 24 показателей верни ровно один объект, в порядке и с id из списка.
- `quote` — дословный фрагмент из текста отчёта (одно предложение или строка таблицы), на котором основана оценка. Не пересказывай и не исправляй его.
- `quote` пустой только если score = 0 по причине «показатель не упоминается».
- `reasoning` — одно-два коротких предложения: какие цифры сравнил и какое правило спецификации применил.
- `score` — целое число от -2 до 2.
- Не считай сумму оценок и не делай итоговый вывод.
