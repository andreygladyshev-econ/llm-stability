# Правила оценки 24 показателей

Оценка −2…+2 = влияние факта на привлекательность акций банка. Знак — по влиянию на акционера, не по направлению цифры.

## Пороги (общие)
- Денежные величины: изменение > 15% → ±2; 3–15% → ±1; < 3% → 0.
- Коэффициенты в %: изменение > 1,5 п.п. → ±2; 0,3–1,5 п.п. → ±1; < 0,3 п.п. → 0.
- Свои пороги у отдельных показателей (ниже) важнее общих.

## Какую цифру брать
1. Прибыль, EPS, ROE, ЧПД, комиссии, NIM, операционные расходы, CIR, стоимость риска, резервы: последний квартал
   против того же квартала год назад (в годовом отчёте — 4 квартал). Нет такой — накопленный период год к году.
2. Портфели, средства клиентов, балансовая стоимость акции, клиенты, пользователи: изменение с начала года,
   без валютной переоценки, если дано. Нет — изменение за квартал.
3. Пороги — к выбранной цифре как есть. Другие периоды не используются.

## Ноль — только в 4 случаях
(а) не упомянуто; (б) уровень без сравнения (кроме состояния с оценочной фразой); (в) изменение ниже порога;
(г) прямо сказано «без изменений». Иначе — не ноль.

## Состояние
Показатели состояния: CIR, стоимость риска, доля рынка, достаточность капитала, дивиденды, качество портфеля,
внешние условия, тон. Уровень без динамики даёт +1/−1 ТОЛЬКО при прямой оценочной фразе в отчёте («выше минимума»,
«комфортный», «ниже целевого», «под давлением»); фраза входит в цитату. Без фразы — по порогам.
