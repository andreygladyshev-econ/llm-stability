# Устойчивые оценки банковских отчётов с помощью языковой модели

Андрей Гладышев, группа Э312
Экономический факультет МГУ

Решение практического задания «Как превратить отчёт банка в цифры, которым можно доверять»: 15 пресс-релизов Сбера
по МСФО за 2022–2026 годы оценены по 24 показателям, измерена и повышена устойчивость оценок между прогонами модели.

## С чего начать

Главный документ — [СДАЧА/ЗАПИСКА.md](СДАЧА/ЗАПИСКА.md).

| папка | что внутри |

## Итог в цифрах

- 91,9% показателей (331 из 360) совпали во всех пяти прогонах; итоговый вывод одинаков в 13 отчётах из 15.
- У всех 245 ненулевых оценок есть дословная цитата из отчёта; выдуманных цитат 0,2%.
- Совпадение с эталонной разметкой 114 из 120 клеток, на отложенных отчётах 68 из 72; грубых ошибок нет.
