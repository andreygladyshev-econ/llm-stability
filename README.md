# Устойчивые оценки банковских отчётов с помощью языковой модели

Андрей Гладышев, группа Э312,
экономический факультет МГУ

Решение практического задания «Как превратить отчёт банка в цифры, которым можно доверять»: 15 пресс-релизов Сбера
по МСФО за 2022–2026 годы оценены по 24 показателям (от −2 до +2, итоговый вывод strong, mixed или weak) с дословной
цитатой под каждой оценкой; каждый отчёт прогнан пять раз, измерена и повышена устойчивость оценок между прогонами.

Главный документ — [ЗАПИСКА.md](ЗАПИСКА.md): итоги, метод, что сработало и что нет. Подробности и ответы на вопросы
задания — в [ПРИЛОЖЕНИЯ.md](ПРИЛОЖЕНИЯ.md).

## Итог в цифрах

- 91,9% клеток (331 из 360) совпали во всех пяти прогонах; итоговый вывод одинаков в 13 отчётах из 15. На четырёх
  отчётах, использованных при настройке, при одной и той же температуре 0,7 исходная спецификация давала 61,5%,
  итоговый метод 88,5%.
- У всех 245 ненулевых оценок есть цитата; все цитаты таблицы совпадают с текстом PDF посимвольно.
- Совпадение с эталонной разметкой 114 из 120 клеток, на отложенных отчётах 68 из 72; ошибок знака нет.

## Пересчёт

Все числа записки воспроизводятся по сохранённым ответам моделей из папки [code](code/README.md) (Python 3.12).
Пересобранные таблицы, векторы и таблица Excel совпадают со сданными побайтно; рисунки совпадают по данным, а пиксели
зависят от шрифта системы.
