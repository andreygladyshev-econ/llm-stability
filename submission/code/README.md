# Код и данные

Здесь лежит всё, что нужно, чтобы пересчитать числа записки и заново собрать таблицу оценок, векторы и рисунки по
сохранённым ответам моделей. Запускать сами модели для этого не нужно.

## Состав

| папка или файл | что внутри |
|---|---|
| [src](src/) | скрипты на Python |
| [specs](specs/) | все проверенные версии спецификации и запросы к модели; v1 совпадает со спецификацией заказчика, итоговая версия [v7_extract.md](specs/v7_extract.md) |
| [raw](raw/) | ответы моделей, по одному файлу JSON на прогон; имя файла содержит модель, версию спецификации, режим, отчёт и номер прогона; в поле meta записаны параметры прогона (температура, порядок показателей, провайдер, время, стоимость); подпапки `_archive` (пробные запуски при настройке) и `_failed` (прогоны, завершившиеся ошибкой) в расчётах не участвуют |
| [raw_qwen_bf16](raw_qwen_bf16/) | 21 ответ облачной Qwen 27B без сжатия (bf16); серия прервана из-за медленного провайдера, ответы используются в сравнении сжатия (final_checks.py, блок E) |
| [text_v2](text_v2/) | текст отчётов, распознанный моделью со зрением и сверенный со скрытым текстовым слоем PDF; по нему получены все итоговые оценки |
| [text](text/) | текст отчётов, распознанный Tesseract; использовался в первых опытах. Там же производные тексты для проверок: без названия банка (`anon_*`), с одним подменённым фактом (`cf_*`) и короткий текст пробных запусков (`smoke_mini`) |
| [pdf_sber](pdf_sber/) | 15 пресс-релизов Сбера по МСФО (сканы PDF), по которым получены оценки; соответствие обозначениям отчётов — notes/pdf_mapping.json |
| [pdf_other](pdf_other/) | пресс-релизы ВТБ и Т-Технологий (текстовые PDF с сайтов банков) для проверки переноса метода |
| [text_pdf](text_pdf/) | скрытый текстовый слой PDF (Сбер) и текст PDF других банков с контрольными суммами; по нему цитаты таблицы переписываются посимвольно (src/pdf_quotes.py), выгрузка: src/export_pdf_text.py |
| [queues](queues/) | описания серий прогонов: модели, версии спецификации, режимы; в `_archive` — пробные запуски при настройке. Рабочие комментарии из этих файлов убраны при подготовке сдачи, параметры серий не менялись |
| [notes](notes/) | соответствие обозначений отчётов исходным PDF (pdf_mapping.json); примечания ручной проверки итоговой таблицы (примечания_проверки.json); описания подменённых фактов (counterfacts.json) |
| [logs/cloud_ledger.jsonl](logs/cloud_ledger.jsonl) | стоимость каждого облачного запроса |
| [outputs](outputs/) | сохранённые выводы всех расчётов, на которые ссылаются записка и приложения |
| [requirements.txt](requirements.txt) | версии библиотек |

Эталонная разметка лежит в соседней папке [../gold_labels](../gold_labels/README.md).

## Как пересчитать

Нужен Python 3.12. Из этой папки:

```bash
python -m pip install -r requirements.txt
python src/audit.py
python src/final_checks.py
python src/deep_analysis.py
python src/deep_analysis2.py
python src/registry_checks.py
python src/qoq_check.py
python src/ocr_order_check.py
python src/build_submission.py
python src/figures.py
```

Каждый скрипт анализа печатает результат в консоль; сохранённые копии этих выводов лежат в папке
[outputs](outputs/). Можно запускать отдельные блоки, например `python src/deep_analysis2.py 16 17`. Скрипты
`build_submission.py` и `figures.py` пишут результат в `code/rebuild/`, чтобы не затирать сданные
файлы. Пересобранные таблицы (включая таблицу Excel) и векторы совпадают со сданными побайтно.
Рисунки совпадают по данным; пиксели зависят от шрифта (Helvetica Neue на macOS, Arial или Liberation Sans в других
системах). Проверка распознавания (`ocr_order_check.py`) берёт PDF из папки [pdf_sber](pdf_sber/).

## Файлы, оставленные без изменений

Версии спецификации в [specs](specs/) — ровно тот текст, который видела модель: его хеш записан в каждом ответе
(`spec_hash` в поле meta), и правка любого символа разошлась бы с прогонами. Поэтому в файлах версий 1 и 2 осталась
ссылка на `ЗАДАНИЕ_прост_рус_яз.md` из текста спецификации заказчика; текст задания в репозиторий не входит.
По той же причине без изменений оставлен
раннер [night.py](src/night.py): хеш его кода вместе с [indicators.py](src/indicators.py) записан в каждом прогоне
на ноутбуке (`code_sha`).

## Как получены данные

Эти скрипты для пересчёта не нужны: они создали данные, которые лежат в этой папке.

| скрипт | что создал |
|---|---|
| [ocr.py](src/ocr.py) | текст отчётов, распознанный Tesseract ([text](text/)) |
| [ocr_v2.py](src/ocr_v2.py), [ocr_bench.py](src/ocr_bench.py) | текст, распознанный моделью со зрением и сверенный со скрытым слоем PDF ([text_v2](text_v2/)); сравнение распознавателей |
| [import_text_pdf.py](src/import_text_pdf.py) | текст отчётов ВТБ и Т-Технологий из текстовых PDF, без распознавания |
| [export_pdf_text.py](src/export_pdf_text.py) | текстовый слой PDF для сверки цитат ([text_pdf](text_pdf/)) |
| [make_variants.py](src/make_variants.py) | тексты без названия банка (`anon_*`) и с одним подменённым фактом (`cf_*`): читает ли модель отчёт или вспоминает банк, меняется ли оценка вслед за фактом |
| [make_specs.py](src/make_specs.py) | варианты спецификации версии 2 из модулей правок ([specs/modules_v2.md](specs/modules_v2.md)) |
| [night.py](src/night.py) | серии прогонов на ноутбуке через LM Studio ([raw](raw/)) |
| [cloud.py](src/cloud.py) | серии облачных прогонов через OpenRouter, стоимость запросов ([logs/cloud_ledger.jsonl](logs/cloud_ledger.jsonl)) |

Для новых прогонов понадобятся LM Studio с моделью Qwen 3.8 27B (MLX, 4 бита) или собственный ключ OpenRouter;
ключ в код не включён. Раннер `night.py` перед запуском проверяет папку, куда пишет сводку о ходе прогонов
(константа `ANDREY` в начале файла); для новых прогонов её нужно заменить своей.
